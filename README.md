# 智居布线 · 全屋智能点位图与弱电布线设计

面向装修小白的可视化 Web 应用：把复杂的强弱电布线变成"搭积木"。上传户型图 → 划分房间 → 拖拽设备 → 自动生成开关回路与线管走向 → 输出材料清单、预算与电工施工交底。

## 9 大界面（左侧导航）

1. **方案首页** — 多方案管理、9 步流程总览、完成度、导入/新建
2. **户型结构** — 上传户型图/手绘照片作底图；拖绘普通墙、承重墙、梁、柱；比例尺校准
3. **区域划分** — 矩形/多边形绘制客厅、卧室、厨房等区域并命名，设备自动归属
4. **点位布局** — 8 大类 30+ 设备库拖拽放置，网格吸附 + 红色辅助线对齐、尺寸标注、属性编辑
5. **场景联动** — 回家/离家/观影/睡眠/起床/用餐模板，按房间+设备类型自动匹配动作
6. **布线设计** — 一键生成开关→灯回路；A\* 算法自动布弱电线管并绕开承重墙/梁/柱；手工布强电管/桥架；点位图⇄布线图切换；强弱电 300mm 间距、穿结构等实时校验
7. **配电箱回路** — 强电点位分配到照明/插座/厨卫/空调回路，点位数与功率超载提醒
8. **清单预算** — 自动统计点位、网线/BV 线/线管/桥架长度，单价可改，导出 CSV，预算估算
9. **施工交底** — 生成电工视角交底书（回路、控制关系、强弱电规范、整改项），可打印/复制/下载
10. **版本分享** — 多版本快照保存/恢复，gzip 压缩链接只读分享，JSON 备份导入导出

## 技术说明

- 零依赖原生 ES Modules + SVG 画布，无需构建
- 线管自动走线：网格 A\*（曼哈顿启发式 + 转弯代价 + 结构外扩安全距离）
- 线长估算：桥架吸附走"引线+沿桥架"，否则曼哈顿走线，按校准比例换算并加施工余量
- 数据存于浏览器 `localStorage`；分享链接用 `CompressionStream` gzip + base64url 编码进 URL hash

## 本地运行

```bash
cd b
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

> 必须通过 HTTP 访问（ES Module 与压缩 API 要求），不要直接双击 index.html。
