# 智居布线 · 全屋智能点位图与弱电布线设计

面向装修小白的全屋智能点位图与弱电布线设计 Web 应用——**把复杂布线，变成搭积木**。
纯前端实现（原生 HTML/CSS/JS + SVG，零构建、零依赖），双击 `index.html` 即可使用；
方案保存在浏览器 localStorage，分享链接把整套方案编码进 URL，无需服务器。

## 快速开始

```bash
# 方式一：直接用浏览器打开
open index.html          # macOS
xdg-open index.html      # Linux

# 方式二：起一个静态服务器（推荐，分享链接/二维码更顺）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

打开后建议先点左侧「✨ 载入演示户型」，内置一套约 90㎡ 两室一厅、32 个点位的完整示例，
可直接体验从设备点位 → 一键布线 → 清单预算 → 施工交底的全流程。

| 3 | 设备点位 | 从 8 大类设备库**拖拽**放灯/开关/插座/传感器/摄像头/窗帘电机等；自动吸附对齐、参考线、尺寸标注；强电红点、弱电蓝点、强弱电一体半圆；改名/旋转/改回路；**一键切换点位图/布线图**；生成开关回路连线 |

外加一个只读的**分享查看页**（`#/view?s=...`），家人/设计师/电工打开即可看图并另存副本。

## 关键实现

- `js/canvas.js`：SVG 世界坐标画布（单位米），缩放/平移、HTML5 拖放、0.5m 网格 + 设备/墙边磁吸、参考线、尺寸标注、墙/梁/柱/区域/线管绘制。
- `js/wiring.js`：A* 寻路（二叉堆、4 邻域、障碍外扩 20cm、承重墙禁穿、隔墙惩罚）、强弱电占用带避让（鼓励 ≥30cm）、同管种并管、直角路径平滑；开关→同区域灯具就近回路；线段最近距离/相交检测输出合规告警。
- `js/report.js`：BOM 聚合、线材/线管长度（含 15% 弯耗与预留）、预算模型、回路负载、施工交底文案、CSV。
- `js/store.js` + `js/util.js`：localStorage 多方案、版本快照、Unicode 安全的 URL Base64 分享编码、自动回路分配。
- `js/data.js`：21 种设备（价格/线规/功率）、4 个场景模板、默认回路与演示户型。

## 说明与边界

- 价格为二线城市 2025 年市场参考价，仅供预算估算，实际以品牌选型与电工报价为准。
- 自动布线是装修方案级示意（沿墙沿顶、绕梁柱、保间距），不替代专业电气施工图；
  承重力结构、接地、漏保等请以当地规范与持证电工意见为准。
- 底图以 dataURL 存入 localStorage/链接，大图建议使用「生成不含底图的精简链接」分享。
